# موقع فنادق ISLEM

موقع ثابت (HTML فقط) لا يحتاج إلى أي تثبيت أو خادم. يعمل مباشرة على GitHub Pages.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كاملًا (التصميم والنصوص في ملف واحد) |
| `images/` | ضع هنا صور الفروع |
| `.nojekyll` | يمنع GitHub من معالجة الملفات، لا تحذفه |
| `README.md` | هذا الشرح |

## 1) إضافة صور الفروع

ضع الصور داخل مجلد `images/` بهذه الأسماء بالضبط (صيغة JPG):

- `branch-1.jpg` للفرع الأول
- `branch-2.jpg` للفرع الثاني
- `branch-3.jpg` للفرع الثالث

إن لم توجد الصورة يظهر مكانها لون متدرّج مع عبارة «[صورة الفرع ...]». للأداء الأفضل اجعل الصورة بعرض 1200 بكسل تقريبًا وأقل من 500 كيلوبايت.

## 2) تعديل النصوص

افتح `index.html` بأي محرر نصوص (مثل Notepad أو VS Code) وابحث عن الأقواس المربعة `[ ... ]` واستبدل ما بداخلها ببياناتك الحقيقية:

- `[الولاية / العنوان]` لكل فرع
- `[وصف قصير للفرع ...]`
- `[رقم الهاتف]` و`[البريد الإلكتروني]` في آخر الصفحة
- أسماء الفروع: «ISLEM – الفرع الأول/الثاني/الثالث»

## 3) رفع الموقع على GitHub

1. أنشئ حسابًا على github.com إن لم يكن لديك، ثم أنشئ مستودعًا جديدًا (New repository) باسم مثل `islem`، واجعله Public.
2. في صفحة المستودع اختر **Add file › Upload files**، ثم اسحب كل محتويات هذا المجلد (وليس المجلد نفسه) وأكمل بـ **Commit changes**.
   - الملف `.nojekyll` مخفي في بعض الأنظمة؛ إن لم تجده أنشئ ملفًا فارغًا بهذا الاسم من **Add file › Create new file**.
3. افتح **Settings › Pages**. تحت Source اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يظهر رابط الموقع في الصفحة نفسها بالشكل:
   `https://اسم-المستخدم.github.io/islem/`

## 4) دومين خاص (اختياري)

في **Settings › Pages › Custom domain** اكتب نطاقك (مثل `islem.dz`) واتبع تعليمات GitHub لضبط سجلات DNS عند مزوّد النطاق.

## ملاحظات

- شريط الحجز في أعلى الصفحة شكل فقط ولا يرسل أي بيانات. لربطه بنظام حجز أو بواتساب أو بريد إلكتروني يلزم تعديل إضافي.
- الخطوط (Amiri وTajawal) تُحمَّل من Google Fonts، فإن لم يتوفر اتصال تظهر خطوط النظام بدلها.
- كل تعديل تحفظه في المستودع ينعكس على الموقع خلال دقائق.
